# Project Brief: Whatsie

Whatsie is a feature-rich, open-source WhatsApp client for Desktop Linux, built with C++ and the Qt framework.

## Core Goals
- Provide a native-feeling WhatsApp experience on Linux.
- Integrate deeply with Linux desktop environments (System Tray, Notifications).
- Enhance privacy and security with features like Application Lock.
- Offer extensive customization (Themes, Zoom, User Agent).

## Key Requirements
- **Engine:** Qt WebEngine (Chromium-based) for rendering WhatsApp Web.
- **Portability:** Support for multiple Linux distributions via Snap, .deb, Flatpak, and AUR.
- **Security:** Selective compilation flags and application-level password protection.
- **UX:** Dark/Light theme support, Spell Checker, Multi-account (OTR) support.
