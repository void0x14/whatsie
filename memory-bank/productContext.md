# Product Context

## Why Whatsie Exists
Linux lacks an official WhatsApp desktop client. While WhatsApp Web works in browsers, it lacks native integration (tray icons, reliable notifications, auto-start, window management) and specific power-user features like application locking.

## Problems It Solves
- **Integration:** Provides a system tray icon for quick access and background operation.
- **Privacy:** One of the few clients with a built-in "App Lock" to prevent unauthorized access to messages.
- **Visuals:** Fixes various WhatsApp Web UI issues on Linux (e.g., square avatars) and supports custom CSS/JS injection.
- **System Footprint:** Offers a dedicated instance that doesn't require keeping a full browser tab open.

## User Experience Goals
- **Native Feel:** The app should blend into Linux desktops (GNOME, KDE, etc.) with proper tray and notification support.
- **Reliability:** Stable rendering using Qt WebEngine.
- **Simplicity:** Easy to use, with all settings accessible through a dedicated widget.
